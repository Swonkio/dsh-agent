# User model

The agent maintains this file itself, across sessions, with the `user_model`
tool — it is the counterpart to SOUL.md (which is the agent's own identity).
It starts as this scaffold and deepens as the agent learns who you are. Edit it
by hand any time; the agent revises it in place rather than only appending.
